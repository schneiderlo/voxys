# Generated game-action icons

These three action icons were produced with the built-in `image_gen` tool on 2026-09-24. The tool does not expose a model-version selector; no specific model version is claimed.

The complete prompt for each icon is in `prompts.json`. `manifest.json` records the original output dimensions, transparency statistics, hashes and source locations. The `*-original.png` files are unchanged generated outputs. `review.png` shows their appearance over a dark game-HUD surface at 96 and 32 pixels.

They represent Ride, Cannon and Save actions. They are not selectable construction pieces and make no claim to depict exact installed model geometry. The installed construction catalogue and player portrait remain direct CPU renders of the real meshes.

The shared atlas baker downsamples these originals into three 64×64 slots while preserving alpha. No hand repainting, background removal or external API fallback was used.
