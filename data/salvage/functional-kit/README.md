# Functional kit candidates

The three installed kit registries select **r08**. This is static asset and
assembly preparation; ASSET-05/ASSET-04 review, G02 and LOOK-01 remain open.
See [the implementation and evidence](../../../docs/validation/salvage/ASSET-05/README.md)
for exact checks, launches, reproduction, known limits and retained failures.

Nine parts have editable Blender sources, three GLBs/LODs, gameplay metadata,
strictly cooked runtime payloads and original procedural palette maps. The
source recipes are frozen in `r08/recipes/`; `tools/salvage_assets/` holds the
maintained recipes. Preserve old versions and the separate pontoon candidate.
Only selected cooked payloads are included in the new browser routes.

The assets are original project work. No external mesh, generated bitmap,
licensed character or logo was used. Their prototype materials and simplified
collision/mass representations are not final art or live machinery acceptance.
