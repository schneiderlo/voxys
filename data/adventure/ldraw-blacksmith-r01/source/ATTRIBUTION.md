# Medieval Blacksmith source attribution

**LEGO set 21325-1 — Medieval Blacksmith**, LDraw model by **Vincent Messenet [Cheenzo]**.
The model and the selected LDraw dependency files are retained byte-for-byte.
No source geometry, source headers, contributor history, or source license notices
have been changed in this directory. Mesh conversion and game placement are
separate derived outputs and must retain this attribution in distribution.

- [Original model page](https://library.ldraw.org/omr/sets/1289)
- [Original MPD download](https://library.ldraw.org/library/omr/21325-1.mpd)
- [LDraw parts library](https://library.ldraw.org/)
- [Original official library archive](https://library.ldraw.org/library/updates/complete.zip)
- [Author's original model notes](https://forums.ldraw.org/showthread.php?pid=40730#pid40730)

The model's `!LICENSE` is CC BY 2.0 (the historical header calls it “CCAL
version 2.0”). The complete recursive source set contains mixed licenses:

They exclude the separate configuration and notice files. Do not relabel the

## Source model's known substitutions

The source author's model notes report these substitutions; they are not changes
introduced by Voxys:

| Source part used | Intended part or decoration |
| --- | --- |
| 11438 | 37614 minifigure shoulder guards |
| 33057 | 42876 turkey drumstick |
| 59 | 66964 greatsword |
| 2431p01 | 2431pr0156 wooden board / nails tile print |
| 3846p45 | 3846pr0040 Black Falcon triangular shield print |
| 10509p02 | 10509pr0007 horse with reddish-brown bridle print |
| 87079 | 87079pr0055 blacksmith sign print |

The author omitted the minifigures. Consequently, a complete dependency closure
means every reference in this MPD resolves; it does **not** mean the source is an
exact inventory/decorations reproduction of the retail set. The game's existing
player figure remains independent of this model.
