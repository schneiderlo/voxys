# Explicit manual support removal

This operation is a D2 manual experiment, not cannon-triggered damage. `ImportedWallPhysics::release(error, optionalSourceId)` preserves the existing no-removal release behavior. With an ID, it requires an intact accepted wall and a current part in an originally validated supported component. Unknown or unsupported parts are refused before staging any mutation.

`ImportedAssembly::prepareRemovePart(expectedRevision, sourceId, error)` makes an immutable candidate: it removes the part record, all incident bonds, and the part's external anchor, increments topology revision, and runs complete physical preparation again. It refuses stale/unknown IDs, exhausted revisions, erasing the entire section, or failed physical/budget validation. Remaining source identities/transforms stay unchanged. No force or displacement is added.

The owner then cuts the existing eligible connections/supports using the remaining source graph and stages the complete replacement through the existing joined GPU boundary. Its published and execution-matched bindings omit exactly the removed source ID. Static query cells publish only after certified settlement. The immutable original remains available to rebuild the complete initial state. A removal leaving no dynamic survivors can publish a settled static result directly.
